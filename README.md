# Somos Luz — demo

Protótipo clicável da app Somos Luz com as alterações propostas.
Site estático: um só ficheiro `index.html`, sem build.

## Publicar no Vercel
- Vercel CLI: dentro desta pasta, `npx vercel --prod`
- Ou: subir a pasta para um repositório GitHub e importar em vercel.com/new
  (Framework Preset: Other · sem Build Command · Output Directory: `.`)
